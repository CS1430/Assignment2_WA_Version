The Cost of College: Try the Program

See how a finished Assignment 2 program behaves, then use it to check your own math to the penny.

This is a demo, not a template. It runs in your browser and is written in JavaScript, not Python, so its code won't help you write yours. The JavaScript is also deliberately obfuscated, so Inspect Element will only show you scrambled code. Use it to see how the program flows and to compare numbers. Your wording and menu design are up to you. Your numbers must match.

TERMINAL · Assignment2

How to use it

  • Click in the terminal, type a yearly cost, press Enter, then type your credits this semester.
  • Choose 1 to 5 to see each result. Q quits. Any other key shows a friendly message.
  • Run your own main.py with the same two numbers and compare. Every dollar amount should match to the cent.

What about option 6?

Option 6 is your Worth It? extension, so it isn't built here. That part is your idea. The guide's section 10 has ideas to start from.

Remember: check.py is still the referee. This demo helps you spot a wrong number early, but only check.py writes your SUBMISSION.txt.
